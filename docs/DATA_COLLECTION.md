# Data Collection — 백지에서 시작하는 자율 수집

> 시드 데이터: **없음.** 사람은 방향(채널/주제)만 제시하고, AI가 원본·클립·성과를 스스로 모은다.
> 핵심 통찰: **인터넷에 이미 정답 데이터셋이 있다.**

## 콜드스타트 해법 — "원본 ↔ 사람 클립" 쌍 발굴

방송사·크리에이터 공식 채널은 **풀영상과 하이라이트 클립을 둘 다** 올린다.
그리고 각 클립의 조회수가 공개돼 있다. 즉 `(원본, 사람이 고른 구간, 성과)` 라벨이 공짜다.

```
공식 풀영상  ──┐
               ├──▶ ALIGNER가 클립을 원본 타임라인에 정렬
공식 클립 N개 ─┘     → (원본, [start,end], 조회수) 라벨 자동 생성
```

이 라벨이 [EVALUATION.md](EVALUATION.md)의 recall 벤치마크 "정답"이자, 모방학습·보상모델의 학습 데이터가 된다.

## 도메인별 소스 전략

| 도메인 | 원본 | 사람 클립(정답)의 출처 | 비고 |
|---|---|---|---|
| **예능** | 방송사 공식 풀/다시보기 | 방송사 공식 "레전드/하이라이트/짤" 클립 채널 | **편집자막 OCR이 강력**. 클립 풍부 |
| **드라마** | 공식 풀회차 | 공식 "명장면" 클립 | BGM·클로즈업 신호. 클립 많음 |
| **영화** | (저작권 강함 — 예고편/공식 클립 위주) | 공식 명장면·예고편 | 풀영상 수집은 신중. 메타 위주 |
| **유튜브 롱폼** | 원본 영상 | 본인/클립 채널의 쇼츠 | 저작권 가장 자유로움. 시작에 적합 |

> **권장 시작점: 유튜브 롱폼 + 예능.** 저작권 여유 + 클립 풍부 + 편집자막 신호. 영화는 메타·공식 클립만 보수적으로.

## 수집 파이프라인

1. **시드 확장** — 사람이 준 채널/주제 몇 개 → 연관 공식 채널·플레이리스트로 자동 확장.
2. **쌍 매칭** — 같은 회차/에피소드의 풀영상 ↔ 클립들을 제목·업로드시기·썸네일·자막으로 매칭.
3. **정렬** — 오디오 지문 + 자막으로 클립을 원본 타임라인에 복원 → 정답 span.
4. **성과 수집** — 클립 조회수·좋아요·댓글수 등 ground truth 약신호.
5. **전처리·캐시** — 원본 멀티모달 피처 추출(1회). 영상 원본은 임시 캐시만.

## 편집자막 OCR — 도메인 특화 공짜 신호

예능 클립의 번인 자막("여기서 빵 터짐", 효과음 자막)은 **사람 편집자가 이미 강조한 포인트**다.
원본에는 보통 이 자막이 없고 클립에만 있으므로:
- 클립 OCR → 강조 타이밍 추출 → 원본 타임라인에 역매핑 → "사람이 중요하다고 본 순간" 라벨 보강.

## 저작권 · ToS 원칙 (필수 준수)

- **오프라인 학습·평가 한정.** 수집물 자동 재발행 금지(특히 드라마/영화/예능 IP).
- **영상 원본 영구저장·재배포 금지.** 타임코드 + 추출 피처(임베딩·자막 텍스트·점수)만 영구 보관. 원본은 처리 후 캐시 만료.
- **공식 API 우선**, rate-limit·robots·ToS 준수. 대량 병렬 스크래핑 지양.
- **출처·라이선스 메모**(`Source.license_note`)를 항상 기록.
- 추후 실제 발행 단계로 가면, 권리 확보된 콘텐츠로만 진행(별도 결정).

## 데이터 품질 게이트

- `align_confidence` 낮은 쌍은 벤치마크/학습에서 제외.
- 중복 클립(같은 순간 여러 채널) 디둡.
- 조회수 극소 표본은 ground truth 가중치 낮춤.

# Architecture

## 전체 구성

```
┌─────────────────────────────────────────────────────────────────┐
│  COLLECTOR  자율 데이터 수집                                       │
│  공식 채널의 (롱폼 원본 ↔ 사람이 만든 클립 ↔ 조회수) 쌍 발굴       │
└───────────────┬─────────────────────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────────────────────┐
│  PREPROCESS  멀티모달 전처리 (원본 1회, 캐시)                      │
│  • ASR(단어 단위 타임스탬프) + 화자분리                            │
│  • 장면 전환 감지 (shot boundary)                                  │
│  • 편집자막 OCR (예능 번인 텍스트 = 핵심 신호)                     │
│  • 오디오 이벤트 (웃음·박수·정적·BGM 고조·효과음)                  │
│  • 얼굴/인물 트래킹 (리프레임·클로즈업 신호)                       │
└───────────────┬─────────────────────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────────────────────┐
│  ALIGNER  클립 ↔ 원본 자동 정렬                                    │
│  사람이 만든 클립이 원본의 어느 [start,end]인지 오디오지문/자막    │
│  매칭으로 복원 → 정답 라벨(human-selected span) 생성              │
└───────────────┬─────────────────────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────────────────────┐
│  UNDERSTAND  영상 전체의 의미·감정·서사 지도화                     │
│  토픽 세그먼트, 스토리 아크, Q&A/대사 쌍, 웃음·하이라이트 후보     │
└───────────────┬─────────────────────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────────────────────┐
│  GENERATOR  후보 구간 생성                                         │
│  다수 후보 윈도우 제안, 경계는 문장/호흡/장면에 스냅, 한 순간당     │
│  여러 변형(다른 in/out)                                            │
└───────────────┬─────────────────────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────────────────────┐
│  EVALUATOR  3층 보상으로 랭킹  ★키스톤★                            │
│  L0 휴리스틱/루브릭(즉시) → 프록시 보상모델(빠름) → ground truth   │
└───────────────┬─────────────────────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────────────────────┐
│  BENCHMARK  오프라인 성능 측정                                     │
│  사람 클립 대비 recall@k, IoU, 경계 정확도 → 리더보드             │
└───────────────┬─────────────────────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────────────────────┐
│  IMPROVER  결과 분석 → 자기개선                                    │
│  L0 프롬프트 재작성 / L1 파이프라인 탐색 / L2 평가자 재학습 /      │
│  L3 정책 파인튜닝  (champion–challenger로 승급)                    │
└───────────────┬─────────────────────────────────────────────────┘
                │
                └──▶ 모든 단계의 결정은 DECISION LOG에 기록 (플라이휠 연료)
```

렌더링(9:16 리프레임 · 자막 번인 · 필러 제거 · 훅 카피)은 **오프라인 벤치마크가 안정된 뒤(Phase 4+)** 붙인다. 처음엔 "어디를 자를까"의 정확도에만 집중한다.

## 멀티모달 신호 표 (도메인 특화)

| 신호 | 추출 방법 | 무엇을 잡나 | 도메인 |
|---|---|---|---|
| 대사/자막 | ASR + 공식 자막 | 의미·하이라이트·명대사 | 전 도메인 |
| **편집자막(번인)** | **OCR** | **편집자가 찍은 포인트(공짜 라벨)** | **예능** |
| 효과음 자막 | OCR | 웃음·강조 타이밍 | 예능 |
| 오디오 이벤트 | 오디오 분류기 | 웃음·박수·정적·긴장 | 예능·드라마 |
| BGM 고조 | 음악 분석 | 감정 클라이맥스 | 드라마·영화 |
| 장면 전환 리듬 | shot detection | 긴장·액션 구간 | 영화·드라마 |
| 클로즈업/표정 | 얼굴 트래킹 + 표정 | 감정 피크 | 전 도메인 |
| 감정 변동성 | 멀티모달 임베딩 | "기복"이 큰 구간 = 쇼츠감 | 전 도메인 |

## 4레벨 자기개선 (상세)

- **L0 프롬프트/룰** — Improver가 실패 사례(낮은 recall 영상)를 분석해 선택 프롬프트·루브릭·임계값을 재작성. LLM reflection 또는 프롬프트 최적화로 자동화.
- **L1 파이프라인** — 후보 생성 전략·신호 가중치·단계 순서를 하나의 "유전자"로 보고 탐색(유전/밴딧/베이지안). 각 구성은 BENCHMARK로 채점. champion–challenger로 보유.
- **L2 평가자(보상모델)** — `클립 멀티모달 피처 → 성과(또는 사람 선택 여부)`를 예측하는 모델 학습. 처음엔 LLM-judge로 시작해, 데이터가 쌓이면 값싼 전용 모델로 distill. **가장 큰 레버리지.**
- **L3 정책 파인튜닝** — 컷 선택·경계 설정·훅 작성 같은 전문 소형 모델을 winner/loser 쌍으로 SFT → DPO → (선택) 보상모델 대상 RL. 싼 레버가 정체될 때만.

## 데이터 우선 원칙

모든 모듈은 자신의 입력 상태, 취한 행동(선택/점수/파라미터), 결과를 `DECISION LOG`에 남긴다.
이 로그가 없으면 자기개선도 없다. → [DATA_SCHEMA.md](DATA_SCHEMA.md)

## 기술 스택 (잠정, 하이브리드)

- 수집: yt-dlp / 공식 API, 메타데이터 DB
- 전처리: ffmpeg, Whisper류 ASR, PySceneDetect, OCR(번인 자막), 오디오 이벤트 분류기, 얼굴 트래킹
- 이해/생성/평가(초기): 멀티모달 LLM API (하이브리드 — 초기엔 API)
- 평가자(후기): 자체 보상모델 (피처 → 점수 회귀/랭킹)
- 정렬: 오디오 지문(chromaprint류) + 자막 매칭
- 데이터: 객체스토리지(피처/임베딩) + 관계형/문서 DB(메타·로그) + 실험 추적
